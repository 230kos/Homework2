## Описание проекта: Интернет-магазин электроники и товаров для дома
## Обзор проекта

Этот проект представляет собой систему управления товарами для интернет-магазина, реализованную на Python с использованием объектно-ориентированного программирования. Система включает:

Управление категориями товаров
Различные типы продуктов (смартфоны, газонная трава, базовые продукты)
Систему подсчета и сложения товаров
Обработку ошибок и исключительных ситуаций
Структура проекта
src/
├── abstract_entity.py       # Абстрактный класс для сущностей
├── base_product.py          # Базовый абстрактный класс для продуктов
├── category.py              # Класс для работы с категориями товаров
├── exceptions.py            # Пользовательские исключения
├── lawn_grass.py            # Класс для газонной травы
├── product.py               # Основной класс продукта
├── product_iterator.py      # Итератор по продуктам
└── smartphone.py            # Класс для смартфонов

tests/                       # Тесты для всех модулей
*main.py                     # Основной скрипт для демонстрации функциональности

## Основные классы

1. Класс Product

Базовый класс для всех товаров в магазине. Содержит:

Название товара
Описание
Цену
Количество на складе

2. Класс Smartphone (наследуется от Product)

Добавляет специфичные для смартфонов свойства:

Производительность
Модель
Объем памяти
Цвет

3. Класс LawnGrass (наследуется от Product)

Добавляет свойства для газонной травы:

Страна-производитель
Срок прорастания
Цвет

4. Класс Category

Управление категориями товаров:

Добавление/удаление товаров
Подсчет среднего ценника
Итерация по товарам
Особенности реализации

Система типов:
Использование аннотаций типов (Type hints)
Проверки типов при операциях с товарами
Обработка ошибок:
Пользовательские исключения (AddProductError, ZeroQuantityError)
Проверка корректности данных при создании товаров
Принципы ООП:
Наследование
Инкапсуляция
Полиморфизм

## Инструкция по установке

1. Выполнить клонирование репозитория Homework2 себе на компьютер
2. В терминале, находясь в корневой папке проекта, активировать виртуальное окружение через poetry
3. В случае отсутствия менеджера проектов _poetry_, выполнить установку пакетов через _pip_ из списка зависимостей в файле __pyproject.toml_
4. Проект содержит данные о транзакциях, которые содержатся в папке data/

## Запуск приложения  
python <name>.py - из корня репозитория проекта
python <_path_>name.py - из другой папки  
<_path_> - путь к файлу <name>.py проекта Homework

## Тестирование
pytest tests/ - все тесты из папки tests
pytest tests/<test_name>.py - запуск конкретного теста
